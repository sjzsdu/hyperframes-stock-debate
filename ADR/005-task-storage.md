# ADR-005 · SQLite 任务账本与隔离产物目录

状态：提案。

## 背景

Pipeline 已产出脚本、配音、画幅、封面和 sidecar，发布以前落盘、结束后回填（stocktalk/pipeline.py:477-515）。CLI 依靠这些数据继续补发（stocktalk/cli.py:653-716、stocktalk/cli.py:932-959）。发布子进程可能遇到长时间无输出与交互挑战（stocktalk/modules/publisher.py:1474-1493）。Web 和桌面需按同一任务 ID 读取一致状态，现有文件适合继续作为可导出产物。

## 备选方案与理由

| 方案 | 取舍 |
| --- | --- |
| sidecar JSON + 文件轮询 | 零新数据库，筛选、互斥和原子重试须额外实现 |
| SQLite + 本地文件 | 事务与过滤足够，应用进程可共存读取；需设计文件提交与恢复 |
| PostgreSQL + 对象存储 + 独立队列 | 适合多主机分工，增加运行费、迁移和跨服务一致性工作 |

## 决策

SQLite 作为平台状态来源，本机文件系统保存内容。启用外键、WAL 和短事务，设置有限 busy timeout；数据目录仅位于本机磁盘。使用 SQLite 迁移版本、备份接口和按类型/股票/创建时间/状态的索引。API 返回版本化 DTO。数据根目录权限仅限服务用户，API 通过受控产物 ID 读受限根，拒绝路径穿越或符号链接逃逸。

| 记录 | 核心信息 |
| --- | --- |
| generation_task | ID、幂等键、输入摘要、股票、类型/模型/配置快照、阶段、状态、失败码、执行次数、领取令牌与时间戳 |
| artifact | 任务 ID、种类、画幅、相对路径、大小/哈希、媒体类型；脚本、封面、成片、字幕、工程和 sidecar |
| publication | 任务、平台、账号引用、状态、画幅、定时、AI 声明、远端结果引用、重试来源和脱敏错误 |
| credential reference | 仅存服务配置引用和账号别名。oneapi 密钥在进程环境，平台登录态由独立私有工具目录持有，SQLite/工作目录不含凭据 |

同一幂等键 + 输入返回原 ID，变更输入返回冲突。服务持有状态目录的进程级独占锁，串行领取生成和发布工作，客户端可并发读写入队。短事务条件更新领取；worker 超时或关闭时取消外部进程组并确认退出，再释放领取。异常退出后启动先清理/确认旧执行器与子进程状态；无法确认时暂停同资源的新任务，人工处理后再开放。一个工作站和共享账号支持单个发布操作，CLI 同账号使用 ADR-004 约定的互斥。网络调用和渲染期间不持有 SQLite 写事务。

生成状态为 queued → running → succeeded/failed/interrupted。产物先写尝试专属 staging，校验后在同一文件系统原子重命名到 immutable 产物目录，再以同一个数据库事务更新索引和任务状态。文件移动后、事务提交前崩溃时无可见成功，重启以清单和版本快照核验，隔离孤儿文件后允许用户重试。重试用新尝试目录，不覆盖已有成片；自动恢复只复用明确完整、可验证的产物。对欠缺元数据的旧 sidecar 继续按旧 CLI 路径使用。后续导入只登记可校验的成片，报告解析按版本做幂等处理。

发布每个平台单独记录，状态为 pending → submitting → succeeded/failed/action_required/outcome_unknown。只在入库后调用外部工具；提交后中断或无明确远端结果，重启记 outcome_unknown。保留审查记录以人工对账或用已有远端查询核对，确认未发布后再显式补发。使用唯一约束防同一任务/平台/账号存在两个活动尝试。明确失败只补当前选中平台，已成功平台保持原报告。审查与报告整理由 API 完成，旧 CLI sidecar 写回协议维持兼容。

## 成本、风险与回退

估算 3–5 人日，固定月费增量 0，库为单文件，执行器采用本机服务生命周期。磁盘满、异常退出与远端重复发布用事务、隔离产物和未知结果状态处理。迁移前停写并备份数据库和文件清单，恢复先到隔离目录验证数目/校验和。新版本回退先停止领取，导出任务/报告及相对媒体索引，恢复旧 schema 的备份并保留新增媒体、报告副本，再用旧 CLI 的 sidecar 通道继续。省略账本会让两端共享、失败对账和筛选依赖目录推断。
